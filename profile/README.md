Robotensor is a Physical AI research and development company. We build frontier robot
intelligence that learns new work from demonstrations, adapts as the work changes, and
carries across robot platforms. Our focus is in-context robot learning: a model that picks
up a new task from what it is shown, with its weights frozen.
