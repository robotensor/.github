Robotensor is a Physical AI research and development company. We build frontier robot
intelligence that learns new work from demonstrations, adapts as the work changes, and
carries across robot platforms. Our focus is in-context robot learning: a model that picks
up a new task from what it is shown, with its weights frozen.

## Attune

[Attune](https://attune.robotensor.ai) is our open competition for adaptive robot
intelligence, run as Bittensor subnet 58. Miners train robot models; validators score them
in simulation under the same conditions, and every result is published in full.

| Competition | Focus | Status |
|---|---|---|
| [Vector](https://attune.robotensor.ai/vector) | Action-aware in-context learning: learn a behavior from one demonstration, adapt the execution | Live |
| [Horizon](https://attune.robotensor.ai/horizon) | Human-video in-context learning with World Action Models | Coming soon |

- **Mine:** `pip install robotensor-attune`, then read [what to submit](https://attune.robotensor.ai/docs/vector/rules/what-you-submit).
- **Validate, or read the code:** [attune-subnet](https://github.com/robotensor/attune-subnet)
